# Menel: Pobiedziska

Prototyp gry przeglądarkowej na telefon w poziomie. Budzisz się o 7:00 w Pobiedziskach, do północy zbierasz butelki z kaucją (plastik 0,50 zł, szkło 1 zł) i oddajesz je w sklepie.

- Gra: `public/index.html` (jeden plik, bez zależności).
- Hosting: Cloudflare Workers ze statycznymi plikami (`wrangler.jsonc`).

Lokalnie: otwórz `public/index.html` w przeglądarce.
